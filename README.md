# Change Request Management Dashboard | Power BI

## Project Overview

The Change Request Management Dashboard is an interactive Power BI project designed to monitor Change Requests (CRs), analyze approval turnaround times, track pending approvals, and review dispute-related metrics.

The dashboard provides a consolidated view of the CR approval workflow across Operations, Finance, Legal, Client, and SRM.

## Business Objectives

- Monitor the overall status of Change Requests.
- Track approved, in-progress, and on-hold CRs.
- Identify departments with pending approvals.
- Analyze average approval turnaround time (TAT) by department.
- Monitor monthly CR volume trends.
- Analyze disputed amounts by CR status.
- Enable interactive analysis using slicers.

## Tools and Technologies

- **Power BI Desktop** — Dashboard development and visualization
- **Power Query** — Data preparation and transformation
- **DAX** — Measures and calculated columns
- **Excel** — Source data and preparation

## Dashboard Features

### 1. KPI Summary
- Total CRs
- Approved CRs
- In Progress CRs
- On Hold CRs
- Pending CR Count
- Total Dispute Amount

### 2. CR Status Distribution
A donut chart showing the distribution of Change Requests by status.

### 3. Department-wise Average Approval TAT
Compares average approval turnaround time across workflow departments.

### 4. Pending CRs by Department
Highlights departments where approval actions are pending.

### 5. Monthly CR Volume Trend
Tracks the number of Change Requests received over time.

### 6. Status-wise Disputed Amount
Compares the total disputed amount across CR statuses.

### 7. Interactive Filters
- Line of Business (LoB)
- CR Type
- CR Received Date

## Business Workflow

The approval workflow represented in this project is:

**Operations → Finance → Legal → Client → SRM**

The dashboard supports monitoring of CR status, approval timelines, and pending workflow stages.
