# Change Request Management Dashboard | Power BI

## Project Overview
This project analyzes Change Request (CR) records to monitor approval progress, department-level turnaround time, and pending approvals. The dashboard helps stakeholders track CR status and identify areas that may require follow-up.

## Business Objective
- Monitor total CRs and their current status.
- Track approved, in-progress, and on-hold requests.
- Identify departments with pending approvals.
- Analyze average approval turnaround time (TAT).
- Monitor monthly CR volume and filter results by business criteria.

## Tools & Technologies
- **Power BI** — Dashboard development and visualization
- **Power Query** — Data preparation and transformation
- **DAX** — KPI calculations and business logic
- **Excel** — Dummy dataset and source data

## Key KPIs
- Total Change Requests
- Approved CRs
- In-Progress CRs
- On-Hold CRs
- Pending CRs

## Dashboard Features
- CR status distribution
- Department-wise average approval TAT
- Pending CRs by department
- Monthly CR volume trend
- Interactive filters for Line of Business (LoB), CR Received Date, and CR Type

## Data & Privacy
This portfolio project uses dummy data for demonstration and learning purposes. It does not contain confidential company or client information.

## Skills Demonstrated
Data cleaning, data modeling, DAX, KPI tracking, dashboard design, trend analysis, and business reporting.

## Project Status
Portfolio project developed for Power BI practice and demonstration.
